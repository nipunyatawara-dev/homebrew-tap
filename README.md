# Homebrew Tap for Nipun Yatawara

Homebrew formulae and casks by [nipunyatawara-dev](https://github.com/nipunyatawara-dev).

## Available Casks

### NetCollect
A native macOS network monitor for tracking per-application data usage across day, week, month, and all-time timeframes.

```bash
brew install --cask nipunyatawara-dev/tap/netcollect
```

Or:

```bash
brew tap nipunyatawara-dev/tap
brew install --cask netcollect
```

### HiDPI Toggle
Menu bar app for controlling external display HiDPI scaling, resolution, and refresh rate on Apple Silicon Macs.

```bash
brew install --cask nipunyatawara-dev/tap/hidpi-toggle
```

Or:

```bash
brew tap nipunyatawara-dev/tap
brew install --cask hidpi-toggle
```

### OmniSync
Desktop workspace hub and Git collaboration dashboard for local and GitHub-backed repositories.

```bash
brew install --cask nipunyatawara-dev/tap/omnisync
```

Or:

```bash
brew tap nipunyatawara-dev/tap
brew install --cask omnisync
```
